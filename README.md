# RideLanka

A responsive frontend prototype for a Sri Lankan vehicle-rental marketplace. It includes district/type search, dynamic vehicle listings, partner membership pricing, and responsive layouts.

## Run locally

Open `index.html` in a browser, or serve it with any static web server.

## Backend handoff

The sample vehicle data in `script.js` is structured for easy replacement with an API response. The search form and partner pricing UI are ready to connect to backend endpoints and payment processing.
